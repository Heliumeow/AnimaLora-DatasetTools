# Web UI 与 禅模式全景指南 (Web UI & Zen Mode Guide)

本工具的 Web UI（`webapp.py`）旨在将 AnimaLoraStudio 前端丰富的高阶组件（虚拟滚动图片墙、拖拽式 Tag 编辑器、词典翻译补全、词频分布面板）和沉浸式全屏**禅模式 (Zen Mode)** 融为一体。

---

## 一、启动与访问

### 1. 构建前端
因为复用了宿主仓库 `studio/web/src` 的 React 组件，首次启动前需要构建一次：
```powershell
d:\AnimaLoraStudio\venv\Scripts\python.exe studio_data\dataset_tools\build_ui.py
```
*构建脚本会自动在 `studio_data/dataset_tools/ui` 与宿主 `studio/web` 之间建立符号链接，共享依赖并编译，产物保存在 `ui/dist/`。*

### 2. 运行本地服务
```powershell
d:\AnimaLoraStudio\venv\Scripts\python.exe studio_data\dataset_tools\webapp.py --port 8765 --open
```
*安全保证：服务默认仅监听 `127.0.0.1` 本机回环地址，不暴露于局域网。*

## 二、主界面工作台布局

```
+------------------------------------------------------------------------------------+
|  dskit › 10_girl                                  [写入已开启 / 仅预览] [🧘 禅模式] |
+------------------+----------------------------------+------------------------------+
| [侧边栏: 筛选与配置]| [中间: 缩略图虚拟滚动网格]       | [右侧: 标注编辑与词频统计]   |
| 根目录路径选择器 | - 虚拟滚动（海量图片流畅加载）    | - [单图编辑] / [批量编辑]     |
| Tag 组合筛选条件 | - 单击：未选时激活单图；已选时勾选 | - Tag 胶囊与 Prose 自然语言  |
| 导出分组与还原点 | - 🔍 放大镜图标：直接切入禅模式   | - TagStatsPanel：高频词统计  |
|                  | - 底部操作日志（精准展示变动摘要）| - 行内 ✎ 改名与一键清洗格式  |
+------------------+----------------------------------+------------------------------+
```

### 1. 安全写入开关 (Live Mode)
* 默认状态下右上角显示黄色 **`[当前为预览 (dry-run)]`** 胶囊。此时进行的所有修改、清空、替换仅在日志中输出影响范围，不写入磁盘。
* 点击右上角 **`【开启写入】`**（变为醒目红色）后，操作才会真正持久化落盘，并自动留存还原点。

### 2. 双通道标注编辑 (Dual-Track Caption)
* **Tags 通道**：展示可拖拽、可补全、带词典翻译的 Tag 胶囊。
* **Prose 通道**：独立多行文本框，容纳如 `Digital illustration of a girl...` 风格的自然语言段落，彼此物理隔离，防止误当做 Tag 切碎。
* **切分测试与方案 4**：提供手动【将当前描述智能切分】按钮，实时将混合文本规范拆解。

### 3. 直觉化单图编辑联动与选图体验
* 在网格中点击任意图片（无论是单击勾选、区间连选、还是再次点击取消勾选），**最后一次被点击的图片均会立即同步作为单图编辑的目标对象**，无需多余操作，完全契合用户心理直觉。

### 4. 窗格间隔线拖拽调整与持久记忆化
* **左右窗格拖拽线**：在图片缩略图墙与右侧编辑面板之间，悬停拖拽垂直分割线可自由拉伸右侧面板宽度（260px ~ 900px）；
* **上下窗格拖拽线**：
  * 左侧网格与底部操作记录之间支持上下拖动调节日志高度；
  * 右侧编辑表单与 TagStatsPanel 之间支持上下拖动调节表单展示高度；
* **双击重置与记忆化**：双击任意分割线即可瞬时恢复默认比例；拖拽调整后的空间尺寸全部持久化保存在浏览器本地（`localStorage`）。

### 5. 目录浏览历史记忆化 (History Memoization)
* 启动应用时自动从本地存储恢复**上次浏览的数据集根目录**，无需每次重复选定；
* 侧边栏「范围」模块自动记录最近浏览的历史目录列表，支持通过下拉菜单一键切换，并提供清空历史选项。

### 6. 主模式与禅模式统一共用「淘汰目录」与记忆化
* **侧边栏淘汰目录卡片**：主界面侧边栏不仅支持主目录选择，还集成了专属「淘汰目录」配置卡片，支持手动输入或通过 `PathPicker` 弹窗选择；
* **默认平行同级目录**：若未设置，默认在父目录下生成 `${root}_rejected` 平行目录，配置与禅模式完全打通并持久化保存在本地；
* **一键恢复与清理**：提供「恢复默认」按钮以及一键递归清理主目录与淘汰目录中所有残留空文件夹的「清理空目录」功能；
* **单图与批量淘汰/放回**：
  * **单图编辑**：选中图片后右上角显示保留/已淘汰状态，并提供 `【🗑️ 淘汰此图】` / `【♻️ 放回训练集】` 快捷按钮；
  * **批量编辑**：支持对选中的多张图片一键 `【🗑️ 批量淘汰 (X)】` 或 `【♻️ 批量放回 (X)】`。

### 7. 主模式与禅模式共用「三态视图」(Three-State View)
* 在主界面缩略图网格顶部提供三态切换按钮组：
  * **`全部 (X)`**：展示主目录与淘汰目录下的完整素材；
  * **`仅保留 (Y)`**：仅展示主目录保留的有效训练素材（严格剔除淘汰目录）；
  * **`仅淘汰 (Z)`**：仅展示淘汰目录中的素材；
* 网格状态指示：淘汰图片在缩略图右下角常显橙色 **`已淘汰`** 警告角标，并在标签预览前缀附带 `[已淘汰]`，一目了然；状态与禅模式无缝实时联动。

### 8. 内部淘汰目录递归隔离与防重复保护 (Recursion Isolation)
* **递归重复陷阱解决**：如果用户选择的淘汰目录位于主目录内部（例如 `D:/dataset/rejected`），在全量扫描时极易引发重复遍历与重影问题；
* **后端安全隔离机制**：后端 `webapp.py` 与选择器内置 `is_relative_to` 嵌套检测：
  1. 遍历主目录时，严格将位于内部淘汰目录的文件跳过剔除；
  2. 随后独立遍历淘汰目录，确保任何图片在 `all` 视图下有且仅有唯一一条记录；
  3. `accept` 视图与目录概览、步数统计中彻底排除内部淘汰目录及其子文件夹；
* **前端贴心预警**：当检测到淘汰目录嵌套在主目录内部时，界面会自动展示醒目的琥珀色警示条：`⚠️ 淘汰目录位于主目录内部，已启用递归隔离防重复`，让用户使用无后顾之忧。

## 三、沉浸式「禅模式 (Zen Mode)」

禅模式是专为**极速视觉复审、坏图淘汰与单张标注精修**设计的全屏 HUD 工作流，汲取了 `select pic (LoRA Dataset Culler)` 的单文件极速盲操精髓。

### 1. 三种切入方式
1. 点击顶部操作栏醒目的 **`【🧘 禅模式 (Z)】`** 按钮；
2. 点击网格中任意缩略图右下角的 **🔍 放大镜** 图标，直接定位到该图片进入禅模式；
3. 在主界面浏览状态下，直接按下键盘快捷键 **`Z`**。

### 2. 核心键盘流速查表

应用在底层通过按键状态机实现了**浏览态**与**编辑态**的彻底解耦：

| 模式 | 按键 / 交互 | 功能说明 |
| :--- | :--- | :--- |
| **浏览态** | **`Space`（空格）/ `X`** | **就地原位切换保留/淘汰**：画面**停留在当前图不自动跳走**（惰性驻留），防止误触；毫秒级在训练集与淘汰目录间移动主图及全部伴生文件。再次按下原路放回。 |
| **浏览态** | **`←` / `↑`** | 切换到**上一张**有效图片。 |
| **浏览态** | **`→` / `↓`** | 切换到**下一张**有效图片。 |
| **浏览态** | **鼠标滚轮** | 向上滚切上一张，向下滚切下一张（内置 160ms 防抖）。 |
| **浏览态** | **`Tab`** | **切入编辑**：将键盘焦点转入右侧 Caption/Tag 输入框。 |
| **浏览态** | **`Esc` / `Z`** | **退出禅模式**：平滑退回主工作台，自动同步更新。 |
| **编辑态** | **正常键入 / 方向键** | 移动文字光标与输入空格，**绝不误触切图或文件移动**。 |
| **编辑态** | **`Tab` / `Esc` / 点击外部** | **退出编辑态并自动写盘**：若文本被修改，自动落盘写入文件并保存备份。 |

## 四、禅模式高级功能

### 1. 深度镜像文件迁移与伴生全家桶
* **默认平行淘汰目录**：若未指定淘汰目录，工具默认在数据集父文件夹下为主文件夹创建一个带 `_rejected` 后缀的同级平行目录（例如 `D:\dataset` $\rightarrow$ `D:\dataset_rejected`）；
* **复用仓库 `PathPicker` 弹窗与记忆化**：点击右上角淘汰目录胶囊，会唤起与主模式相同的树状文件夹选择器（`PathPicker`），选中的自定义目录会自动针对当前数据集做本地记忆（`localStorage`），下次打开自动恢复；
* **镜像结构归档**：当某张图片被淘汰（Reject）时，工具在淘汰目录下自动创建**结构完全相同的多级相对镜像子目录**（如 `10_girl/portrait/sample_01.png` $\rightarrow$ `reject_dir/10_girl/portrait/sample_01.png`）；
* **伴生全家桶打包**：配对的所有伴生文件（`.txt`、`.json`、`.caption`、`.txt.bak`、`.caption.bak`、`.tags`、`.prompt` 等）全部打包镜像迁移，绝不产生遗漏孤儿；
* **秒级反悔放回**：再次按下空格即可毫秒级原路移回训练集。

### 2. 画质预警与分桶比例推导
* **低清警报**：大图视口实时探测图片的实际物理分辨率（`naturalWidth` × `naturalHeight`），短边小于门槛（默认 1024px）时，顶部胶囊醒目标红：`⚠ 768×1024 px`；
* **分桶比例匹配**：自动将图片长宽比与 SDXL / Flux 常用的标准训练分桶（`1:1`、`3:4`、`4:3`、`16:9`、`9:16`、`2:3`、`3:2` 等）进行欧式距离匹配推荐；
* **极端画幅报警**：长宽比大于 2.3 或小于 0.43 时以暖橙色高亮报警。

### 3. 左侧可折叠多层级文件树导航 (`ZenFolderTree`)
* **双向自动联动**：
  * 在中央视口按方向键或滚轮切图时，左侧目录树会自动展开该图所在的全部父文件夹，并自动平滑滚动（`scrollIntoView`）将当前项呈现在视野中央；
* **层级进度胶囊**：每个文件夹右侧标出 `📁 folder (保留数 / 总数)`，实时感知子集筛选进度；
* **单键折叠与展开**：
  * 点击顶部状态栏的 **`📁 目录`** 按钮随时切换侧栏显示；
  * 面板右上角提供 `❮` 快捷收起按钮；收起时左上角浮动显示 `📁 目录树` 胶囊，点击即可拉开。

### 4. 三态视角过滤 (Three-State View)
顶部栏支持一键切换全局视角：
* **`👁 视图: 全部`**：遍历当前范围内的所有素材；
* **`✔ 视图: 仅保留`**：专注复盘已保留的训练素材；
* **`✘ 视图: 仅淘汰`**：专注检查被剔除的文件，方便二次捡漏；
* 配合**惰性驻留**：在“仅保留”视图下将当前图淘汰时，画面不会突兀跳走，只有当你再次主动按方向键翻页时，才会滑向下一张保留图片。

### 5. 一键清理空文件夹 (`clean-empty`)
大批量淘汰文件后，源目录或淘汰目录可能留下大量空子文件夹。点击顶部 **`🧹 清空目录`** 按钮，工具将由深到浅递归安全清理残留空目录，避免训练器报空目录加载错误。

### 6. 禅模式视口窗格自由拉伸
* 左侧多层级目录树与右侧标注面板两侧均配备**极简垂直分割拖拽线**；
* 鼠标悬停变蓝并可左右自由拖拽扩展目录树或标注区宽度，双击自动恢复默认（目录树 260px，标注面板 380px），同样支持本地独立持久记忆。
