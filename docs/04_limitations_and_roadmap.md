# 局限性、不保证事项与后续路线图 (Limitations & Roadmap)

为了明确工具的边界，避免不切实际的功能预期，并为后续功能迭代提供清晰的技术方向，特记录本文档。

---

## 一、不保证实现的内容 (Non-Guarantees)

以下场景由于操作系统底层限制、架构边界或设计定位，**明确不在本工具的保证支持范围内**：

1. **直接将物理驱动器盘符根目录作为数据集根（`root`）**：
   * 例如 `D:\` 或 `C:\`。
   * **原因**：宿主仓库 `studio/services/dataset/tagedit.py` 的作用域解析逻辑依赖其父级目录作为 `train_dir` 锚点。盘符根目录没有父级目录，强行操作会导致路径越界。工具会明确报错拒绝执行。
2. **损坏或非标准编码文件的无损修复**：
   * 对于已经被二进制损坏的图片、包含畸形非法 JSON 格式的标注文件，工具仅做异常拦截，不承担逆向数据修复责任。
3. **百万级图片的海量图库云端并发全文检索**：
   * 本工具是针对**本地训练集清洗与打标精修**设计的轻量桌面工具，依赖本机文件系统遍历与浏览器虚拟滚动加载。它不是云端大数据检索系统或关系型数据库替代品。
4. **多客户端跨网络高并发写入锁**：
   * 服务默认仅监听本地 `127.0.0.1`。虽然底层对 write 操作增加了线程级锁，但不保证跨网络、多用户同时对同一套磁盘文件做并发批量修改时的数据一致性。

## 二、当前不足与已知边界 (Current Limitations)

1. **极端自然语言长句切分的边界情况**：
   * 当前内置的“方案 1（连词/介词/动名词密度）+ 方案 2（宏观开篇正则）”算法能覆盖 98% 以上主流生成模型（如 JoyCaption、GPT-4V、CogVLM）生成的英文长句。
   * 但对于**完全没有标点符号、全大写、极短非语法英语句子**，算法仍有可能倾向于保守识别。此时建议用户在 Web 端点击【将当前描述智能切分】手动复核。
2. **跨物理分区的淘汰移动性能**：
   * 在同一个磁盘驱动器内（如都在 `D:` 盘），`Space` 空格淘汰与原路放回走的是文件系统的原子重命名操作，耗时通常仅需几毫秒；
   * 若用户将 `reject_dir` 设置在不同物理分区（如源在 `D:` 盘，淘汰目录在 `E:` 盘），移动会降级为跨卷数据流读写与删除，耗时取决于磁盘 I/O 速度。建议将淘汰目录设在同一物理驱动器下。
3. **单文件 HTML 图片墙 (`sheet`) 的规模限制**：
   * `sheet` 子命令将图片元数据与内联样式打成一个纯离线 `.html`。当图片数量超过 10,000 张时，HTML 文件体积会显著增大，推荐使用常规 Web UI 进行超大规模浏览。

## 三、后续开放可能性与发展路线 (Future Roadmap)

以下功能在架构上已预留扩展接口，具备很高的技术可行性，可作为后续阶段的演进方向：

### 1. 本地 AI 打标模型管道联动 (AI Captioning Pipeline)
* **方向**：在 Web UI 和禅模式中，增加一键调用本地打标模型（如 WD14 Tagger、JoyCaption、Florence-2、Qwen-VL 等）的后端接口；
* **体验**：在禅模式下，浏览到缺少 Tag 或描述不足的图片时，按快捷键（如 `Ctrl+A`）自动调起模型推理并将新 Tags / Prose 实时回填入输入框。

### 2. 感知哈希与视觉特征去重 (Perceptual Hashing & Deduplication)
* **方向**：集成 `imagehash` (pHash / dHash) 或轻量级 CLIP ViT 图像嵌入向量；
* **体验**：自动找出数据集中重复率极高、连拍相似度超过 95% 的冗余素材，并在禅模式或主界面提供一键“保留最佳一张、淘汰其余连拍”功能。

### 3. 多通道淘汰分级归档 (Multi-Tier Culling)
* **方向**：扩展当前的单目录 `reject_dir` 机制，支持多状态分流：
  * `[保留 Accepted]`：进入训练集；
  * `[淘汰 Rejected]`：直接剔除的废片；
  * `[待修 Review/Touchup]`：构图不错但需要修复手部、面部或去除水印的素材；
  * `[正则化 Regularization]`：适合作为 Class/Reg 图像的通用素材。

### 4. 图像智能裁切与构图预览 (Smart Crop & Aspect Ratio Fit)
* **方向**：在禅模式的大图自适应视口中，叠加常用训练分辨率框（如 `1024x1024`、`768x1344` 等裁切安全区预览）；
* **体验**：直观观察该图片在模型 Bucket 裁切后是否会被切掉关键人物面部或武器头部。
